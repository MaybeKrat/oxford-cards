# Источники словаря

В приложении **3000 карточек Oxford 3000**: A1 — 900, A2 — 800, B1 — 700, B2 — 600. Используется закреплённая опубликованная британская редакция списка по CEFR. Это не официальный продукт Oxford University Press.

## Английские слова и CEFR

- Описание списка и критериев отбора: [Oxford Learner’s Dictionaries](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000).
- Первоисточник: *The Oxford 3000™ by CEFR level*, © Oxford University Press, 12 страниц.
- [Адрес оригинального PDF](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf).
- Фактически использована опубликованная копия PDF из [ittuann/The-Oxford-5000-Word-Lists, commit 7dc22b8ff8e5cb3410e962b0511d22cdf74b120c](https://raw.githubusercontent.com/ittuann/The-Oxford-5000-Word-Lists/7dc22b8ff8e5cb3410e962b0511d22cdf74b120c/The_Oxford_3000_by_CEFR_level.pdf). Локальная копия: `src/data/sources/oxford3000-by-cefr.pdf`.
- SHA-256 PDF: `b81e3f65c976fc93eb342ba34c40f0ff8c3a59646312d09ac50f9c648e461cd3`.
- Дата получения и сверки: 25 октября 2026 года.

Редакция закреплена для воспроизводимости карточек и сохранения прогресса. Это **не заявление об использовании последней редакции**. На дату сверки текущий PDF Oxford содержал небольшие изменения: например, в нём появились AI, podcast и vaccine, а CD и DVD были исключены. Приложение намеренно сохраняет исходную опубликованную редакцию из 3000 записей.

Нумерованные омографы и отмеченные Oxford отдельные значения сохраняются отдельными карточками: `can` (мочь / банка), `bank` (банк / берег), `wind` (ветер / наматывать). Поэтому 3000 карточек соответствуют **2979 различным написаниям**, а не 3000 уникальным строкам. `a, an` — одна запись, как в закреплённом PDF. Карточки не дополнены посторонними словами для достижения круглого количества.

Если одна запись встречается на нескольких уровнях для разных частей речи, карточка получает минимальный уровень, а части речи объединяются. Исходные части речи и уровни сохранены без потерь в `src/data/sources/oxford-headwords.json`. Отдельный идентификатор карточки вычисляется из исходного ключа Oxford, включая различитель омографа. Сортировка и правка перевода не изменяют идентификатор.

## Русские переводы и примеры

- Автор прямо указывает в README, что материалы созданы с помощью GPT-4.
- Лицензия MIT, **Copyright (c) 2024 Mustafa D.** Полный текст сохранён в `src/data/sources/en-ru-LICENSE.txt` и должен распространяться вместе с материалами.

В `src/data/sources/translation-overrides.json` находятся независимые переводы для отсутствующих записей и исправления неоднозначных значений. Они подготовлены с использованием ИИ при создании приложения. В частности, раздельно переведены омографы, различены May/may и IT/it, исправлены значения will, used to и patient. Для таких записей старый пример не переносится автоматически, чтобы он не противоречил переводу.

**Русские переводы и английские примеры не являются официальными переводами или примерами Oxford. Полная редакторская проверка 3000 карточек не проводилась.** Короткая подсказка на карточке не охватывает все значения слова и не заменяет словарную статью. Источник конкретного перевода воспроизводимо определяется импортом: сначала точный ключ из файла исправлений, затем слово из CSV. Количество исправлений и примеров записано в `src/data/metadata.json`.

PDF, выбор слов, уровни и наименование Oxford сохраняют исходную атрибуцию и права Oxford University Press. MIT-лицензия переводного набора не перелицензирует материалы Oxford. Проект не содержит ключей Oxford API, аудиофайлов Oxford или полных словарных статей.

## Темы для изучения

В `src/data/word-topics.json` каждому из 3000 стабильных идентификаторов явно назначена одна из 26 тем. Это независимая разметка приложения, подготовленная с использованием ИИ по значению, переводу и части речи карточки; она не является официальной классификацией Oxford. У многозначных слов тема относится к представленному на карточке значению. Отдельные омографы размечены по своим идентификаторам. Полная редакторская проверка перевода и разметки не проводилась.

Порядок тем и их названия находятся в `src/lib/topics.ts`. Новые слова группируются сначала по CEFR A1 → A2 → B1 → B2, затем по теме; внутри темы используется стабильный алфавитный порядок. Планировщик пропускает уже начатые карточки, поэтому продолжение темы определяется существующим прогрессом без нового курсора в сохранениях. Повторения остаются отсортированы по сроку, независимо от темы.

`npm run check:data` проверяет полное соответствие тематической разметки идентификаторам словаря, отсутствие неизвестных тем и лишних карточек. Эта проверка также запускается перед сборкой приложения. При изменении исходного списка требуется обновить тематическую разметку; импорт переводов не перезаписывает её.

## Воспроизводимость и проверка

Для запуска приложения Python и доступ к сети не требуются: готовый JSON уже включён в проект.

Обычная сборка данных требует Python 3.9+ и только стандартную библиотеку:

```powershell
python scripts/import-vocabulary.py
python scripts/import-vocabulary.py --check
```

Импорт полностью локальный. Он проверяет 3000 записей, уникальность идентификаторов, отсутствие пустых русских переводов, допустимость CEFR и совпадение набора английских слов с закреплённым источником. `--check` также проверяет полное совпадение с включёнными в проект JSON-файлами.

Для повторного извлечения исходных записей непосредственно из сохранённого PDF дополнительно нужен пакет `pypdf`:

```powershell
python -m pip install pypdf
python scripts/import-vocabulary.py --extract-source
python scripts/import-vocabulary.py --check
```

Импорт сохраняет разрывы уровней и обе перенесённые строки частей речи в PDF. Любая неизвестная строка или другое количество записей завершает импорт с ошибкой, чтобы изменение издания не прошло незаметно.

Файлы `src/data/oxford3000.json` и `src/data/metadata.json` генерируются автоматически. Переводы следует исправлять в `translation-overrides.json`, затем повторять импорт.
