# Oxford Cards

Локальное приложение англо-русских карточек с интервальным повторением. Включает 3000 карточек закреплённой британской редакции Oxford 3000: A1 — 900, A2 — 800, B1 — 700, B2 — 600. Отдельные значения одного написания представлены разными карточками: всего 2979 различных написаний.

## Обычный запуск в Windows

Скачайте **Oxford-Cards.exe** из [последнего релиза](https://github.com/MaybeKrat/oxford-cards/releases/latest) и запустите двойным щелчком. Достаточно одного EXE для **Windows x64**: установка приложения, Node.js и папка исходного проекта не нужны. Приложение работает в отдельном окне; повторный запуск возвращает уже открытое окно. При желании создайте обычный ярлык EXE на рабочем столе.

Верхняя полоса окна пустая и служит для перетаскивания; цвет левой панели доходит до верхнего края. Справа доступны сворачивание, разворачивание и закрытие. Начальный размер — 1400 × 920 логических пикселей с учётом масштаба Windows. На небольшом мониторе приложение открывается развёрнутым в доступной рабочей области. Слева — меню, серия занятий по дням недели и доля начатых слов Oxford 3000 по уровням; на «Практике» карточка занимает всю доступную высоту, а в невысоком окне шрифты и кнопки становятся компактнее. В узком окне меню переезжает вниз.

Карточки, шрифты и записи произношения включены в EXE; интернет нужен только для переходов к внешним словарям. Записи лежат в репозитории (`public/voices/`), поэтому есть и в самостоятельной сборке. Слово без записи читает установленный английский голос Windows. При самостоятельной сборке файл появится в `release/Oxford Cards.exe`.

В **Настройки → Внешний вид → Тема оформления** доступны «Как в Windows», «Светлая» и «Тёмная». По умолчанию приложение следует системной теме приложений Windows и переключается сразу, без перезапуска, вместе с верхней панелью окна. Ручной выбор сохраняется между запусками и в резервных копиях. Старый прогресс автоматически получает системный режим. В веб-версии системная тема определяется браузером.

Прогресс приложения хранится в `%APPDATA%\Oxford Cards`, отдельно от EXE. Закрытие окна полностью завершает приложение; при следующем запуске прогресс восстанавливается. Переименование или обновление EXE не удаляет прогресс. Не удаляйте этот каталог, если хотите сохранить обучение.

Для переноса прогресса между компьютерами или из веб-версии используйте **Настройки → Скачать копию**, затем **Восстановить из файла** в приложении на другом устройстве. Веб-версия и EXE используют разные хранилища. Передача самого EXE не переносит личный прогресс.

Для самостоятельной сборки EXE в Windows и создания ярлыка выполните команды после клонирования проекта и установки зависимостей, описанных ниже:

```powershell
npm run build:exe
.\scripts\create-desktop-shortcut.ps1
```

Записи произношения всех карточек уже лежат в `public/voices/` (около 86 МБ). После добавления карточек, например нового фильма, недостающие записи дописывает `python scripts/build-voices.py` (нужны `pip install edge-tts` и интернет; уже записанные слова пропускаются).

Разработчикам: `npm run desktop` открывает последнюю сборку `dist` через Electron. `npm run build` обновляет эту сборку. Обычному пользователю эти команды не нужны.

Иконка хранится в `public/favicon.svg`. Команда `npm run build:icons` создаёт из этого же векторного исходника PNG и Windows ICO с размерами от 16 до 256 px. Сборка EXE запускает её автоматически, поэтому иконки сайта и приложения совпадают.

## Запуск веб-версии для разработки

Нужен **Node.js 24** с npm. В PowerShell:

```powershell
git clone https://github.com/MaybeKrat/oxford-cards.git
cd oxford-cards
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). Оставьте терминал работающим; `Ctrl+C` останавливает сервер. Первичная установка пакетов требует доступа к интернету. Словарь уже включён в проект, поэтому для обычной практики загрузка слов из сети не нужна.

В Windows также можно запустить `Start-App.ps1` из каталога проекта:

```powershell
.\Start-App.ps1
```

Скрипт установит зависимости через `npm ci`, если папки `node_modules` ещё нет, и запустит сервер на том же адресе. Если порт 5173 занят уже запущенным экземпляром, откройте его или остановите прежний сервер.

## Как заниматься

На странице «Практика» вспомните перевод, откройте ответ и оцените себя. Сначала идут карточки, срок которых наступил, затем новые слова выбранных уровней: от A1 к B2, тематическими группами внутри каждого уровня. Темы проходят автоматически: «Люди и семья», «Дом и быт», «Еда и напитки» и далее — всего 26 тем. Название темы видно на карточке и в подробностях слова. Когда все новые слова темы изучены, начинается следующая; после перезапуска занятие продолжается с оставшихся слов. Уже изученные карточки сохраняют своё расписание и не проходят заново как новые.

Дневной лимит относится только к новым карточкам; повторения не ограничены. Настройки позволяют менять лимит, уровни, направление перевода и автоматическое произношение. «Словарь» сохраняет алфавитный порядок для поиска. Тематическая разметка — независимая группировка приложения, не официальная классификация Oxford.

Когда занятие закончено, экран «Готово на сегодня» показывает итог дня: сколько карточек пройдено, примерное время, долю ответов «Помню» и «Легко», число новых слов и когда следующее повторение. На кнопке «Трудные ещё раз» — сколько слов сегодня получили «Не помню» или «Сложно». Кнопка **«Ещё 10 слов на сегодня»** добавляет следующую порцию новых карточек выбранных уровней. Её можно нажимать снова после каждой порции; если осталось меньше десяти слов, кнопка покажет их количество. Обычный лимит в настройках не меняется. Добавленные слова доступны до конца текущего местного дня, в том числе после закрытия приложения; завтра снова действует обычный лимит. Уже изученные дополнительные слова сохраняются и участвуют в интервальном повторении.

| Действие | Клавиша | Следующий интервал |
| --- | --- | --- |
| Открыть ответ | Пробел | — |
| «Не помню» | 1 | 1 минута |
| «Сложно» | 2 | При первой оценке новой карточки — 1 час; далее не менее 1 дня, предыдущий интервал × 1,2, но не дольше «Помню» |
| «Помню» | 3 | 1 день, затем 6 дней, затем интервал × коэффициент лёгкости. После «Не помню» или часа «Сложно» — снова с 1 дня |
| «Легко» | 4 | Около 4 дней (3–5 с учётом разброса) и всегда хотя бы на день дольше «Помню»; предыдущий интервал × коэффициент лёгкости × 1,3 |

Над карточкой — полоска занятия: сколько ответов уже дано сегодня, сколько осталось повторений и новых слов и примерное время до конца (по вашему обычному темпу ответов). Там же переключатель мода фильма, кнопка с динамиком — автоматическое произношение, та же настройка, что **Настройки → Произносить автоматически**, — и режим фокуса: он прячет боковые колонки и оставляет только карточку (выход — та же кнопка или Esc). Справа сводка «Сегодня»: новые слова из дневной цели, повторения, доля ответов «Помню» и «Легко» за день; под ней число повторений на завтра и блок «Мод фильма»: до двух фильмов — включённый (или последний, который вы учили) и тот, что ближе всего к просмотру. Нажатие на карточку фильма включает его, повторное нажатие на включённый фильм (он обведён зелёным) выключает мод. У каждого фильма одинаково показаны доля изученных слов и доля понятной речи; в них входят и уже выученные слова Oxford, поэтому фильм может быть частично знаком ещё до включения мода.

Если слово не вспоминается, клавиша **E** (или ссылка под карточкой) показывает английский пример до ответа; в направлении «Русский → Английский» само слово в примере скрыто. После ответа пример показан с выделенным словом, а под переводом — последние оценки этой карточки. Кнопка **«Трудные ещё раз»** на экране «Готово на сегодня» прогоняет сегодняшние трудные слова повторно: ответы «Ещё раз» (1) и «Помню» (2) в этом прогоне не меняют расписание.

Клавиши 1–4 работают после открытия ответа. Горячие клавиши не перехватывают ввод в текстовых полях и списках; на кнопке или ссылке Пробел сохраняет обычное действие браузера. «Отменить» возвращает состояние до последней оценки.

Используется модификация [SM-2](https://www.super-memory.com/english/ol/sm2.htm), а не точная реализация исходной шкалы из шести оценок. Начальный коэффициент лёгкости — 2,5; оценки меняют его в пределах 1,3–5. Интервалы от одного дня округляются вверх. Часовой интервал «Сложно» применяется только при самой первой оценке карточки; уже назначенные повторения не меняются. Ошибка сбрасывает последовательность успешных ответов; после «Не помню» успешный ответ «Помню» начинает её с одного дня. «Не помню», пока слово ещё ни разу не вспомнилось, коэффициент лёгкости не снижает: промахи при первом знакомстве не делают слово «трудным» навсегда. Карточка считается закреплённой при интервале от 21 дня.

Новая карточка расходует дневной лимит при первой оценке, даже если ответ — «Не помню». Лимит и серия занятий считаются по местной календарной дате устройства. Интервалы от одного дня считаются в учебных днях: учебный день начинается в 4:00, и повторение приходит в 4:00 нужного дня; ответ ночью до 4:00 относится к предыдущему дню. Интервалы от трёх дней получают разброс ±5%, но не меньше дня — чтобы слова, начатые в один день, не возвращались все вместе; у одной карточки при одном ответе разброс всегда одинаковый, поэтому срок на кнопке совпадает с назначенным. Одна минута после «Не помню» и час «Сложно» отсчитываются от времени ответа. Дневной лимит новых слов и серия занятий по-прежнему считаются по календарной дате (с полуночи). Очередь обновляется каждые 15 секунд и при возвращении в окно приложения.

### Моды по фильмам

Мод выбирается прямо на «Практике»: кнопка «Выбрать фильм» над фильмами справа (или переключатель над карточкой) открывает меню: что включено сейчас, два фильма, которые ближе всего к просмотру (подборка меняется раз в день), «Выключить мод» и «Все фильмы». У каждого фильма в меню — доля изученных слов и понятной речи с полоской и кнопка «Включить». «Все фильмы» открывают окно со всеми фильмами: поиск по русскому и английскому названию, фильтр «Начатые», сортировка «Ближе к просмотру» или по названию. На каждом фильме видно, какая доля его речи понятна уже сейчас по выученным словам и сколько слов осталось выучить. Выбор также доступен в **Настройки → Мод фильма**. Сейчас доступны «Дюна» и «Зверополис» (Zootopia), в обоих модах — обе части. Одновременно активен один мод. Новое слово, которое есть в нескольких фильмах, — одна карточка с общим прогрессом. Пока в моде есть неначатые слова, дневной лимит новых слов и кнопка «Изучить сегодня ещё 10 слов» берут только их, от частых в фильме к редким; выбранные уровни на слова мода не влияют. Потом продолжается обычная очередь Oxford. Повторения идут как обычно.

В мод входят все слова фильма из Oxford 3000 — это те же карточки с общим прогрессом, — а также новые слова и термины мира фильма. Вместо уровня у новых карточек метка «Дюна», у терминов — «Термин Дюны» и короткое пояснение. В «Словаре» их можно выбрать отдельным фильтром по названию фильма. При выключении мода новые слова фильма пропадают из словаря и повторений, но их прогресс сохраняется и возвращается при включении.

Слово мода считается изученным, если последний ответ на нём — «Помню» или «Легко». На «Практике» карточка фильма показывает долю изученных слов мода и долю речи фильма, которую они покрывают (частые слова весят больше). На «Прогрессе» те же числа приведены для обеих частей вместе и для каждой части, а также сколько слов мода ещё не начато. Общая статистика Oxford 3000 новые карточки фильма не учитывает; в блоке «Как держатся слова» они показаны отдельной строкой «Фильмы» — общей для всех модов.

«Словарь» содержит поиск по английскому слову и русскому переводу, фильтры уровня, стадии памяти и темы. В таблице у каждого слова — стадия памяти (от 0 до 4 делений) и дата следующего повторения. Подробности открываются панелью справа: все значения слова с одинаковым написанием, пример, история ответов, интервал и число ошибок.

«Прогресс» показывает:

- число начатых слов, слов с интервалом от 7 дней, долю ответов «Помню» и «Легко» за 7 дней и серию занятий;
- «Как держатся слова» — пять стадий памяти по интервалу повторения: «Новые» (не открывали), «Учу» (меньше дня), «Знакомые» (1–6 дней), «Уверенно» (7–20 дней), «Закреплено» (от 21 дня); те же стадии по уровням A1–B2 и строкой «Фильмы»;
- «Повторения впереди» — сколько карточек придёт на повторение в каждый из следующих 14 дней, самый загруженный день выделен;
- «Занятия» — календарь ответов по дням, начиная с недели первого ответа (не больше 8 недель).

В EXE слова звучат записями британских нейроголосов Microsoft — Ryan (по умолчанию) или Sonia, выбор в **Настройки → Голос**. Записи всех карточек Oxford 3000 и модов фильмов сделаны заранее и встроены в приложение, поэтому звук начинается сразу и не зависит от голосов Windows. Слово без записи заранее полностью синтезируется в WAV установленным английским голосом Windows. Оба варианта проигрываются через Web Audio. Записи хранятся только в памяти; подготовка записи сама по себе не включает звук и не раскрывает ответ обратной карточки. Перед первым воспроизведением и после простоя добавляется короткое беззвучное начало записи для запуска аудиовыхода. Этот приём не гарантирует устранения аппаратной задержки конкретных наушников.

Кнопка звука подсвечивается во время подготовки и речи; повторное нажатие проигрывает запись с начала. Быстрые нажатия объединяются в последний запрос. При смене карточки, закрытии подробностей или сворачивании приложения прежняя речь останавливается. Если подготовка или воспроизведение не удаются, приложение сообщает об ошибке и позволяет повторить нажатие. В веб-версии используется отдельный контроллер голосов браузера; наличие голоса и необходимость сети зависят от браузера.

## Прогресс и резервные копии

В Windows-приложении настройки, статистика и расписание повторений хранятся в локальном профиле `%APPDATA%\Oxford Cards`, отдельно от EXE. В веб-версии используется `localStorage` текущего браузера. Облачной учётной записи и синхронизации между устройствами нет. В настройках используйте «Скачать копию» и «Восстановить из файла». Перед заменой прогресса приложение проверяет JSON и просит подтвердить восстановление.

В веб-версии данные привязаны к адресу сайта, включая порт: `127.0.0.1`, `localhost` и сервер предпросмотра на порту 4173 имеют разные хранилища. Для переноса между ними используйте резервную копию. Очистка данных сайта удаляет прогресс веб-версии; удаление профиля `%APPDATA%\Oxford Cards` удаляет прогресс Windows-приложения.

Открытые вкладки одного адреса получают изменения через событие `storage`. Перед сохранением приложение сверяет исходное состояние и просит повторить действие, если другая вкладка уже изменила прогресс. В браузерах с Web Locks записи дополнительно выполняются по очереди под общей блокировкой. Без Web Locks остаётся проверка состояния, но строгая блокировка одновременных записей недоступна.

Если сохранённые данные повреждены, приложение блокирует их автоматическую перезапись. В настройках можно скачать исходные данные для восстановления, загрузить исправную копию либо подтвердить начало заново.

## Сборка и проверки

```powershell
npm run build
npm test
npm run check:data
```

`build` проверяет TypeScript и создаёт статическую сборку в `dist`. `test` запускает тесты планировщика, хранения, озвучивания, начальных размеров окна и ограничений десктопной оболочки через встроенный `node:test`. `check:data` проверяет 3000 записей, уникальные идентификаторы, структуру, непустые русские переводы и распределение CEFR закреплённой редакции. Проверка данных не оценивает лингвистическую точность переводов.

Для просмотра готовой сборки выполните `npm run preview` и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сценарии проверок описаны в [QA.md](QA.md).

### Подготовка к просмотру «Дюны»

30.10.2026 Иван попросил сопоставить английскую лексику фильмов «Дюна» (2021) и «Дюна: Часть вторая» (2024) со словарём приложения. Исследование и частотный отчёт с поиском находятся локально в `work/dune-vocabulary/dune-vocabulary.html`; исходные ссылки, методика, ограничения и скрипты — рядом. По доступным транскриптам Springfield словарь покрывает около 87% употреблений, примерно 93% после исключения выделенных имён и терминов мира. Это не оценка знания слов Иваном или понимания речи. Транскрипт второй части пропускает некоторые реплики на вымышленных языках, поэтому цифры не описывают весь текст фильма. На основе исследования 30.10.2026 собран набор мода «Дюна»: 1086 карточек Oxford, 300 новых слов и 41 термин. Источники описаны в [DATA-SOURCES.md](DATA-SOURCES.md). Как пользоваться модом — раздел «Моды по фильмам».

### Данные словаря

Сверка 31.10.2026 с первоначальным частотным отчётом: все 14 рекомендованных слов представлены в моде, причём `reverend` — в карточке `Reverend Mother`. Из 341 новой карточки 328 совпадают с написаниями отчёта напрямую, остальные 13 соответствуют составным терминам или исправленным формам слов. Это проверка состава, не редакторская проверка переводов. Детали: `work/dune-vocabulary/comparison-2026-10-31.json`. Старый HTML-отчёт отражает только базовый Oxford 3000 и не учитывает добавленный мод.

Английские слова и уровни взяты из закреплённой опубликованной редакции Oxford 3000; это не утверждение об использовании самой последней редакции. **Русские переводы и примеры неофициальные, подготовлены с использованием ИИ и не прошли полную редакторскую проверку.** Независимое приложение не связано с Oxford University Press.

Источники, версии, хеши исходных файлов, атрибуция и воспроизводимый импорт перечислены в [DATA-SOURCES.md](DATA-SOURCES.md). Для сомнительных переводов на карточках есть ссылка на Cambridge Dictionary.

`src/data/oxford3000.json` генерируется автоматически. Для правки переводов изменяйте `src/data/sources/translation-overrides.json`, затем выполняйте команды импорта из `DATA-SOURCES.md`. Стабильные идентификаторы сохраняют прогресс при исправлении перевода и сортировки.
